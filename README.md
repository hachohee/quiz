  버튼을 누르면 플레이어 바로 위에 대본 시트가 열리고, 재생되는 문장이 자동으로 하이라이트·스크롤됩니다.
- **주제·흐름 요약**(2026-11-22 추가): 플레이어 **제목 아래**와 대본 시트 **상단**에 그 회차의 주제와 흐름을 한국어 2~3줄로 표시합니다.
  듣기 전에 무슨 내용인지 먼저 파악하는 용도라, 플레이어에서는 2줄로 줄여 보여 주고(누르면 시트가 열립니다) 시트에서는 전체가 보입니다.
- **자막 싱크**(2026-11-22 v18 재작성): `timeupdate`(브라우저별 약 250ms)만 쓰지 않고 재생 중에는 `requestAnimationFrame`으로
  `currentTime`을 매 프레임 추적합니다(play·playing·ratechange·seeked·waiting·loadedmetadata·화면 복귀·대본 열기 모두에서 추적을 되살림).
  시작 **0.22초 앞당김**, 짧은 틈(≤2.5초)은 직전 문장 유지로 깜박임 없음, 0.45초 안쪽 틈은 다음 문장으로 미리 넘김,
  광고·음악처럼 긴 공백에서만 하이라이트를 비웁니다.
- **자동 따라가기 스크롤**(v18): 브라우저 `smooth` 스크롤(거리에 따라 400~900ms)에 맡기지 않고 **직접 140~260ms tween** 으로
  현재 문장을 위 32%에 놓습니다. 그래서 '내가 옮긴 스크롤'을 사용자 스크롤로 오판해 따라가기가 저절로 꺼지는 일이 없고,
  따라가기 해제는 **손으로 미는 동작**(터치 드래그·휠·스크롤바 드래그·방향키)에서만 일어납니다. 문장이 화면 밖으로 밀리면
  0.24초마다 확인해 다시 끌어오고, `⤓ 지금 문장으로 따라가기`를 누르거나 문장을 탭하면 다시 따라갑니다.
- **보기 모드**: `영+한 같이` / `영어만` / `숨기기`(이 폰에 `tmq_radio_script_mode_v1`로 저장).
- **문장 탭**: 문장을 누르면 그 `start` 초로 점프해 바로 재생 — 받아쓰기·복습용.
- **대본 없는 회차**(한국 라디오·지난 회차)는 오디오만 나오고 `이 회차는 아직 대본이 준비되지 않았어요` 한 줄만 표시됩니다.

  해석 파일 형식은 `{"summary":"…", "skip":[…], "fix":{…}, "ko":{…}}` (스크립트 상단 설명 참고).

  ```

  ```

### ⚡ 광고 길이 차이 자동 보정 (2026-11-23 v22)

**"자동 보정해줘 안그럼 내가 못찾아"** — CNN 회차는 대본 시각이 폰이 받은 음원과 어긋나면 자막이 15~45초 밀려서,
어느 문장을 듣고 있는지 손으로 찾기가 어렵습니다. 그래서 **재생이 시작될 때 오디오 길이 차이를 재서 자막 시각을 스스로 맞춥니다.**

- **원인 실측(2026-11-23)**: CNN 5 Things 음원은 megaphone DAI 라서 회차 중간(또는 끝)에 광고가 끼는데,
  같은 회차를 여러 번 받아 보니 **1010.55(광고 없음) · 1040.74 · 1055.56 · 1070.50 · 1080.48 · 1085.73초** 로 달랐습니다.
  본편 오디오를 직접 받아 적어 비교하니 어긋남은 **광고가 끼는 지점마다 계단처럼** 생겼습니다
  (예: 'She Clocked in as a Nurse' 회차 → 대본 53.4초 뒤에서 **+29.7초**, 'Revisiting: RFK Jr.' 회차 → 대본 614.8초 뒤에서 **+30.1초**;
  광고가 짧게 끼는 날은 +15초, 끝에만 끼는 날은 본편은 그대로).
- **데이터**: `radio_transcripts.json` 의 `_meta[key]` 에 **`adBreaks: [{"at": 53.35, "add": 29.71}]`**
  (그 `at` 이후 문장이 `add`초만큼 뒤로 밀린다는 뜻)와 `adRef: {dur, sum, scanned}`(측정에 쓴 파일 길이)를 기록합니다.
  대본 자체에 광고가 박혀 있던 자리(문장 사이 **8초 이상 틈**)는 `{"at": 580.76, "add": 0, "gap": 43.19}` 로 함께 넣어,
  폰이 받은 음원에 그 광고가 **없을 때(음수 차이)** 도 그만큼 당겨 맞춥니다.
  BBC·6 Minute 는 광고 없는 고정 원본이라 `adBreaks` 자체가 없고, **앱도 손대지 않습니다.**
- **앱 동작**: `loadedmetadata`·`durationchange` 에서 `diff = audio.duration − meta.audioDur` 를 재고,
  `|diff| ≥ 2초`면 광고 지점마다 **`min(기준 길이, 남은 diff)`**(모자라는 경우는 `−gap` 까지)를 차례로 얹습니다.
  보정이 걸리면 대본 시트 맨 위에 **`⚡ 광고 길이 차이 자동 보정 +30초`** 배지가 뜨고, 처음 한 번은 토스트로도 알려 줍니다.
  배지의 `끄기`를 누르면 **그 회차만·그 폰에서만** 자동 보정을 끕니다(`tmq_radio_ad_auto_off_v1`, 다시 누르면 켜짐).
  기존 **싱크 ±10초/±1초 바**는 그대로라, 자동 보정 뒤에 남는 미세 오차는 손으로 더 맞출 수 있습니다.
  (v22 로 처음 열 때, 예전에 CNN 회차에 손으로 맞춰 둔 싱크 값은 자동 보정과 겹쳐 두 번 밀리지 않도록 **한 번만** 지웁니다. BBC 값은 그대로 둡니다.)
- **문장별 단어·숙어·표현(`v` 칩)·요약·재생 기능은 그대로**입니다. 보정은 대본 시트가 쓰는 시각 배열만 바꿉니다.
- **다시 재는 법**: `python3 scripts/scan_ads.py --audio ep.mp3 --key "cnn5things::<guid>" [--write]`
  (오디오를 받아 적어 문장별 오차의 '계단'을 찾아 `adBreaks` 를 냅니다). `align_transcripts.py --write` 도 정합이 끝나면 같은 값을 자동으로 다시 계산해 넣습니다.
  `check_data.py` 는 `adBreaks` 의 형식·순서·범위(`at` ≤ `audioDur`, `add` −2~180초)까지 검사합니다.
