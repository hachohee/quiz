# CNN 5 Things 음원 광고(DAI) 실측 — 2026-11-23

똑똑핫초 `hachohee/quiz` v22 '광고 길이 차이 자동 보정'의 근거 데이터.
측정 방법: 회차 MP3를 내려받아 faster-whisper(base.en) 단어 타임스탬프를 뽑고,
`radio_transcripts.json`의 사람이 다듬은 대본 문장을 전역 정렬(difflib)해
**문장별 (실제 시각 − 대본 시각)** 오차를 계산 → 오차가 '계단'처럼 바뀌는 지점 = 광고 삽입 지점.

→ **프리롤은 없음**(첫 문장 0.0초). 광고는 회차 중간 1~2곳 + 끝(포스트롤)에 끼고,
길이는 세션(UA·요청 시각)마다 0 / 15 / 30 / 45초로 달라진다. 총 길이 차이만으로는
'어느 지점에 몇 초'인지 알 수 없어, 대본에 기록한 광고 지점(`adBreaks`)과 함께 쓴다.

## 3) 앱 동작 규칙 (v22 `index.html`)

```
D = audio.duration − meta.audioDur
|D| < 2 → 보정 없음
그 외 → 광고 지점마다 take = D>0 ? min(add, D−used) : max(−max(add,gap), D−used)
        (|take| < 2 이면 건너뜀) → 그 at 이후 문장 start/end 에 누적 적용
```
- 배지: 대본 시트 상단 `⚡ 광고 길이 차이 자동 보정 +30초/-30초`, `끄기`는 회차별·폰별 저장(`tmq_radio_ad_auto_off_v1`).
- BBC·6 Minute는 `adBreaks` 자체가 없어 앱이 손대지 않음(실측 파일 길이 = audioDur로 고정).
- v22 첫 실행 때 CNN 회차에 저장돼 있던 예전 손보정(±) 값은 자동 보정과 겹치지 않게 1회 삭제.

## 4) 재측정 명령

```
python3 scripts/scan_ads.py --audio ep.mp3 --key "cnn5things::<guid>"      # 미리보기
python3 scripts/scan_ads.py --audio ep.mp3 --key "cnn5things::<guid>" --write
python3 scripts/align_transcripts.py --prog cnn5things --audio ep.mp3 --key "cnn5things::<guid>" --write   # 정합 시 자동 갱신
```
